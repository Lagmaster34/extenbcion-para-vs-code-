# Capturas del README

Aquí van las imágenes que el README referencia:

| Archivo | Qué debe mostrar |
| --- | --- |
| `overlay.png` | El overlay anclado en una esquina, sobre código real |
| `bienvenida.png` | El aviso de la primera ejecución con el botón "Elegir GIF o vídeo" |

Dos cosas a tener en cuenta:

- **Usa un GIF propio o con licencia CC0.** Nada de material con derechos de autor,
  ni fotogramas de series o películas.
- **Esta carpeta está en `.vscodeignore`,** así que no engorda el `.vsix`. Al
  publicar, `vsce` reescribe las rutas relativas del README para que apunten al
  repositorio, de modo que las imágenes tienen que estar subidas a GitHub para que
  se vean en el Marketplace.

Cuando las tengas, descomenta las líneas correspondientes en el README.
